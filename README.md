# 📝 Diário Moderno com Tkinter

Este é um aplicativo de diário pessoal desenvolvido em Python utilizando a biblioteca **Tkinter**. Ele permite que o usuário registre, visualize, edite, busque e apague anotações de forma simples e intuitiva.

---

## 📦 Funcionalidades

- ✅ Salvar anotações com data e hora automaticamente
- ✅ Visualizar todas as anotações salvas
- ✅ Editar ou apagar anotações existentes
- ✅ Buscar por palavras-chave nas anotações
- ✅ Interface gráfica amigável e responsiva

---

## 🖥️ Pré-requisitos

- Python 3.x instalado
- Biblioteca `tkinter` (já vem com o Python padrão)
- Editor de texto ou IDE (VSCode, PyCharm, etc.)

---

## 🚀 Como Executar

1. Clone o repositório:
    ```bash
    git clone https://github.com/seunomeusuario/diario-tkinter.git
    cd diario-tkinter
    ```

2. Execute o script:
    ```bash
    python diario.py
    ```

> Um arquivo chamado `diario.txt` será criado automaticamente para armazenar suas anotações.
